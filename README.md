# Mélodie en Fête — La Fête de la Musique en France

A bilingual (French/English) interactive website about France's Fête de la Musique.

## Run the website
1. Keep `index.html`, `css/`, `js/`, and `videos/` together.
2. Open `index.html` in a modern browser.
3. Click or tap once anywhere on the page to allow the browser to start the background piano.

## Included features
- French / English language switch
- Interactive map of French regions (clicking a region opens its information only; no regional sound playback)
- Festival history, worldwide expansion, stories and trivia
- Music genres and French festival cuisine with food photography
- Interactive quiz
- Two videos displayed directly after the quiz
- Synthesized Pachelbel Canon in D-inspired piano background arrangement

The background piano is synthesized by the website; no external recording is bundled.

## Project structure
- `index.html` — website page
- `css/style.css` — visual styling
- `css/animations.css` — animations
- `js/` — application, map, quiz, audio and translations
- `videos/festival-video-1.mp4` and `videos/festival-video-2.mp4` — the two supplied videos
